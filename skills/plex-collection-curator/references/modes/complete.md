# Plex Collection Complete Mode

Use only when the user explicitly asks for end-to-end collection work that includes collection membership, missing-media fill, and posters.

1. Run the audit flow to establish the master list and local coverage.
2. Update Plex collection membership for available items.
3. Run fill-missing for missing media after the required download-path safety checks.
4. Run posterize for the collection and matched items.
5. Report counts, additions/searches, poster source, skipped ambiguous items, and verification limits.
