# Plex Collection Audit-Only Mode

Use when the user asks to audit, check, review, compare, or list collection coverage without requesting Plex, Arr, download, or poster changes.

1. Build the smallest reliable master list needed for the requested collection.
2. Check Plex libraries read-only for matching movies/shows.
3. If the user believes an item exists on disk, inspect only the relevant library root discovered from Plex.
4. Report present, missing, ambiguous, and optional entries compactly.

Do not create collections, add media, trigger searches, scan Plex, or apply posters.
